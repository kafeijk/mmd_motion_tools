# MMD Motion Tools

用于 MMD 角色动作与相机动画批量修改的 Blender 插件，让改动作更简单高效。适用于 Blender 3.2 及以上版本。

## 安装

1. 编辑 → 偏好设置 → 插件 → 从磁盘安装 → 选择插件压缩包。
2. 勾选启用插件。
3. 插件依赖 **MMD Tools**，请先安装并启用。

启用后，在 3D 视图按 `N` 打开侧边栏，即可看到 **MMD Motion** 面板。

## 主要功能

### 穿模检测

选中 MMD 模型后执行，等待进度条结束后，会显示穿模帧数与部位。

- **时间范围**：检测的时间范围，与场景时间范围一致。
- **检测预设**：提供的用于穿模检测的参数预设，可选择「通用」或「素体」。
- **代理精度**：用于检测的代理的面数大小，素体类模型推荐「完整」，非素体类推荐「均衡」或「极简」。
- **手部罩体**：在左右手各生成一个罩体包裹手部，并以罩体代替手部参与穿模检测。适用于素体类模型的布料解算，但也会增加修改动作的难度，且执行耗时增加。
- **显示检测项目**：显示用于穿模检测的检测项，即检测部位。可按需勾选手部、小臂、大臂与躯干、胸部、头部、下肢等部件组合。
- **自定义拓展**：通过指定额外骨骼名称，扩展网格的检测范围，例如裙子等部位。可输入多个骨骼名，用中英文逗号分隔，也可用右侧按钮吸取当前选中的骨骼。
- **删除临时对象**：执行后删除用于穿模检测的代理对象。**手部罩体及其专用的手部代理不属于临时对象**，开启此项也会保留在场景中，方便继续修改动作。

检测结果会按连续的穿模帧区间列出，点击起止帧可快速跳转；点击结果右侧的图标可查看「当前帧」的穿模类型。结果支持「预览模式」和「专注模式」两种显示方式，后者会随「当前帧」自动翻页。

### 查找重复动作

用于找出动作中重复的片段。

1. 进入姿态模式，选中需要检查的骨骼。
2. 点击「查找」或「强力查找」。
3. 在结果列表中查看重复的帧区间，点击起止帧可跳转；点击箭头图标，可将前侧重复区间关键帧的增删改同步到后侧重复区间。

- **查找**：仅匹配完全相同的动作区间，速度快。推荐成对选择左右对称的骨骼，例如「左大臂」与「右大臂」、「左小臂」与「右小臂」；也可按需灵活组合骨骼并多次尝试，找出重复帧数最多的组合。
- **强力查找**：允许一定误差的模糊匹配，适用于动补等全帧插入的情形，速度较慢，仅支持单个骨骼。

### 角色动作批量修复

在姿态模式下直接调整骨骼，再把「当前帧」的姿态变化批量应用到选中的关键帧范围，无需逐帧修改。

1. 进入姿态模式，选中需要修改的骨骼。
2. 在摄影表（Dope Sheet）或时间线中选中要修改的关键帧范围，并确保「当前帧」位于该范围内。
3. 调整骨骼姿态。
4. 点击「应用修改」，插件会计算当前姿态与关键帧姿态的差值，并将其应用到整个选中范围。

配套工具：

- **同步范围选择**：把活动骨骼选中的帧范围同步到其他已选骨骼。
- **取消范围选择**：取消所有骨骼关键帧的选中状态。
- **删除内侧帧**：删除选中范围内部的关键帧，仅保留两端边界。
- **删除外侧帧**：删除选中范围外侧指定边距内的关键帧。

### 相机动作批量修复

针对 MMD 相机，按镜头片段批量调整相机运动。

1. 选中 MMD 相机或其根对象。
2. 将「当前帧」移动到需要修改的位置，点击「查找片段」，即可自动选中所在镜头片段的关键帧范围。
3. 在面板中调整相机的位置、旋转、角度或距离。
4. 点击「应用相机修改」，将调整量应用到选中的关键帧范围。

- **查找片段**：根据「当前帧」查找相机动画中的一段连续镜头。

## 其他工具

**通用工具**面板还提供以下功能：

- 模型 / 动作导入导出、装配变形（调用 MMD Tools）。
- 简化骨骼、翻转姿态。
- 仅导入 VMD 中的物理骨骼关键帧，以及移除、禁用、恢复物理骨骼动画。
